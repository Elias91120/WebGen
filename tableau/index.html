Le tableau de bord de l'équipe : les joueurs, les jeux, les mises à jour, le site.

En ce moment

Les joueurs en jeu (un signe toutes les 5 minutes), les duels des Actes, la page du jeu ouverte.

Cette semaine

Des joueurs distincts : chaque installation du jeu compte une fois, quel que soit le nombre de parties.

Les trois jeux

Le temps de jeu compte aussi les parties jamais finies (≈ 5 min par signe) : c'est le meilleur juge de ce qui plaît.

Les 30 derniers jours

Les joueurs de chaque jeu, jour par jour. Touchez une colonne pour lire le jour.

Les mises à jour

Sur quelle version jouent-ils, et combien ont téléchargé chaque version.

Les meilleurs scores

Les classements mondiaux, tels que les joueurs les voient dans le jeu.

Le site

3geeks.fr et la page du jeu : ce qu'ils regardent, combien de temps, et où ils s'en vont.

Les visiteurs, jour par jour

Mesure anonyme : un numéro tiré au hasard par installation du jeu (jamais un nom ni une adresse), un numéro de visite par onglet sur le site, aucun cookie, « ne pas me suivre » respecté ; les joueurs qui coupent « Stats anonymes » dans les options ne comptent pas. Les jeux mesurent à partir de la 0.13.0, le site à partir du 18 octobre. Les chiffres se rafraîchissent seuls chaque minute.
